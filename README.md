# Анализ банковских транзакций

Курсовая работа: приложение для анализа выгрузки транзакций из Т-Банка (Tinkoff).
Реализованы веб-страницы «Главная» и «События», сервисы (кешбэк, Инвесткопилка, поиск),
отчёты на pandas и набор тестов на pytest.

## Возможности

### Веб-страницы (`src/views.py`)

- **Главная** — приветствие по времени суток, сводка по картам (траты + кешбэк),
  топ-5 транзакций, курсы валют и цены акций из пользовательских настроек.
- **События** — расходы и поступления за период (`W` / `M` / `Y` / `ALL`),
  топ-7 категорий + «Остальное», отдельно «Переводы» и «Наличные»,
  курсы валют и цены акций.

### Сервисы (`src/services.py`)

- **Выгодные категории повышенного кешбэка** — сколько можно заработать по каждой
  категории за указанный месяц.
- **Инвесткопилка** — сумма, которую удалось бы отложить при округлении трат до
  порога 10 / 50 / 100 ₽.
- **Простой поиск** — поиск по подстроке в описании и категории без учёта регистра.
- **Поиск по телефонным номерам** — регулярное выражение поддерживает форматы
  `+7 921 11-22-33`, `8 900 000-00-00`, `89000000000`.
- **Поиск переводов физлицам** — категория «Переводы» + имя и первая буква
  фамилии с точкой в описании (например, `Валерий А.`).

### Отчёты (`src/reports.py`)

- **Траты по категории** — за последние 3 месяца от указанной (или текущей) даты.
- **Средние траты по дням недели** — за последние 3 месяца.
- **Средние траты в рабочий / выходной день** — за последние 3 месяца.

Все отчёты обёрнуты декоратором `report_decorator`, который сохраняет результат
в CSV-файл. Декоратор работает как без параметра (имя по умолчанию
`<имя_функции>_report.csv`), так и с параметром — произвольным именем файла.

## Настройка данных

1. Скачайте выгрузку транзакций из личного кабинета Т-Банка в формате `.xlsx`.
2. Создайте папку `data/` в корне проекта (если её нет).
3. Поместите файл как **`data/operations.xlsx`**.

Ожидаемые колонки (русские названия из выгрузки Т-Банка):

| Колонка                       | Тип         | Описание                                  |
|-------------------------------|-------------|-------------------------------------------|
| Дата операции                 | date        | Когда произошла транзакция                |
| Дата платежа                  | date        | Когда был произведён платёж               |
| Номер карты                   | str         | Последние 4 цифры номера                  |
| Статус                        | str         | `OK` / `FAILED`                           |
| Сумма операции                | float       | Сумма в оригинальной валюте               |
| Валюта операции               | str         | Валюта операции                           |
| Сумма платежа                 | float       | Сумма в валюте счёта                      |
| Валюта платежа                | str         | Валюта счёта                              |
| Кешбэк                        | float       | Размер полученного кешбэка                |
| Категория                     | str         | Категория транзакции                      |
| MCC                           | int         | Код категории                             |
| Описание                      | str         | Описание транзакции                       |

Если ваш файл называется иначе — поправьте `EXCEL_PATH` в `src/main.py`
или передайте путь в функции чтения.

### `user_settings.json`

```json
{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
}
```

Отредактируйте списки под себя — эти валюты и акции будут отображаться
на страницах «Главная» и «События».

## Запуск

Из корня проекта, в активированном `.venv`:

```bash
python -m src.main
```

Скрипт последовательно вызывает:
1. `main_page_view` — данные для «Главной».
2. `events_page_view` — данные для «Событий» (месяц).
3. Все сервисы: кешбэк, Инвесткопилку, три поиска.
4. Все три отчёта.

Результаты отчётов сохраняются в `reports/`.

Если хотите вызвать конкретную функцию из REPL:

```python
from src.utils import read_transactions_from_excel
from src.views import main_page_view

txs = read_transactions_from_excel("data/operations.xlsx")
print(main_page_view("2024-05-20 14:30:00", txs))
```

## Тесты

```bash
pytest -v
```

Покрыто:

- `test_utils.py` — загрузка настроек, чтение Excel, приветствие по времени.
- `test_views.py` — приветствие, карты, топ-5, топ-7 + «Остальное»,
  переводы/наличные.
- `test_services.py` — Инвесткопилка, простой поиск, поиск телефонов
  (разные форматы), поиск переводов физлицам.
- `test_reports.py` — три отчёта на pandas, фильтрация по дате и категории.

Тесты не ходят в сеть — курсы валют и цены акций подменяются или игнорируются
в юнит-тестах, поэтому запуск возможен без интернета.

### Настройка `pytest.ini`

```ini
[pytest]
pythonpath = .
testpaths = tests
```

Именно `pythonpath = .` позволяет тестам импортировать `from src.services import ...`.

## Модули

### `src/utils.py`

- `load_user_settings()` — читает `user_settings.json`.
- `read_transactions_from_excel(path)` — читает Excel → `List[Dict]`.
- `read_transactions_dataframe(path)` — читает Excel → `pd.DataFrame`.
- `fetch_currency_rates(currencies)` — курсы ЦБ РФ через `cbr-xml-daily.ru`
  (ошибки логируются и не пробрасываются).
- `fetch_stock_prices(tickers)` — цены акций через Yahoo Finance
  (ошибки логируются и не пробрасываются).
- `get_greeting(dt)` — приветствие по временному интервалу.

### `src/views.py`

- `main_page_view(dt_str, transactions)` — JSON-словарь для «Главной».
- `events_page_view(dt_str, transactions, interval=None)` — JSON-словарь для
  «Событий». `interval`: `'W'`, `'M'` (по умолчанию), `'Y'`, `'ALL'`.

### `src/services.py`

- `cashback_categories(transactions, year, month) -> str` — JSON-строка.
- `investment_bank(month, transactions, limit) -> float`.
- `simple_search(transactions, query) -> str`.
- `search_phone_numbers(transactions) -> str`.
- `search_person_transfers(transactions) -> str`.

### `src/reports.py`

- `report_decorator(filename=None)` — декоратор для сохранения отчёта в CSV.
- `spending_by_category(df, category, date=None) -> pd.DataFrame`.
- `spending_by_weekday(df, date=None) -> pd.DataFrame`.
- `spending_by_workday(df, date=None) -> pd.DataFrame`.

## Примеры использования

### Курс валют

```python
from src.utils import fetch_currency_rates
print(fetch_currency_rates(["USD", "EUR"]))
# [{'currency': 'USD', 'rate': 73.21}, {'currency': 'EUR', 'rate': 87.08}]
```

### Инвесткопилка

```python
from src.services import investment_bank
from src.utils import read_transactions_from_excel

txs = read_transactions_from_excel("data/operations.xlsx")
print(investment_bank("2024-05", txs, 50))
# 54.0  # 1712 -> 1750 (38), 1234 -> 1250 (16)
```

### Отчёт по категории

```python
from src.utils import read_transactions_dataframe
from src.reports import spending_by_category

df = read_transactions_dataframe("data/operations.xlsx")
print(spending_by_category(df, "Супермаркеты", "2024-05-20"))
```

## Источники данных API

| Данные       | Источник                               | Ключ |
|--------------|----------------------------------------|------|
| Курсы валют  | https://www.cbr-xml-daily.ru/daily_json.js | не требуется |
| Цены акций   | https://query1.finance.yahoo.com/v8/finance/chart/{ticker} | не требуется |

Все внешние вызовы обёрнуты в `try/except` и логируются. Если API недоступен,
возвращается пустой список — страница не падает и продолжает работать.

## Критерии, которые покрывает проект

- [x] Приветствие по временному интервалу (06:00–11:59 / 12:00–17:59 / 18:00–22:59 / 23:00–05:59).
- [x] Информация о картах (последние 4 цифры, сумма расходов, кешбэк).
- [x] Ровно 5 транзакций с полями `date`, `amount`, `category`, `description` в формате `dd.mm.yyyy`.
- [x] Все валюты из настроек отображены, `currency` и `rate` присутствуют.
- [x] Все акции из настроек отображены, `stock` и `price` присутствуют.
- [x] Обязательные блоки на месте: `expenses`, `income`, `currency_rates`, `stock_prices`.
- [x] Диапазон корректен, данные сгруппированы и округлены до целых.
- [x] Топ-7 категорий + «Остальное», переводы и наличные выделены.
- [x] Ошибки API обработаны, данные при этом отображаются.
- [x] Кешбэк по категориям, не менее 3 категорий, корректный JSON.
- [x] Поиск по подстроке без учёта регистра — все релевантные результаты.
- [x] Поиск телефонов в нескольких форматах (`+7 921 …`, `89000000000`).
- [x] Поиск переводов физлицам с шаблоном «Имя Ф.».
- [x] Отчёты на pandas, три месяца, декоратор без параметра и с параметром.
- [x] Юнит-тесты на pytest, проверка через `flake8` (`max-line-length = 100`).
